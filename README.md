## ✨ v2.1.0 核心更新亮點

1. **🏷️ 檔案頂端與導覽列新增 Version 標記 (`v2.1.0`)**
   - 於 `index.html`、`style.css`、`script.js` 檔案標頭與頂部導覽列清楚標示目前版本 `v2.1.0`。
2. **📱 首頁精簡為「兩步驟大字速查介面」（專供銷售與現場備料使用，零財務成本干擾）**
   - **STEP 1 — 分類選擇品項與欲製作數量**：
     - 將 20 款配方分為四大類別（`🍞 經典吐司與肉桂捲`、`🥖 人氣軟歐與鹹香軟法`、`🍰 法式常溫甜點`、`🥣 自製酵種與內餡抹醬`），點選分類即可展開該類品項，避免一次全部攤開。
     - **移除中間的「配方倍率」區塊**，僅保留超大字體的「**🎯 本次欲製作數量（整數進位）**」加減控制與快速數量按鈕。
   - **STEP 2 — 直接給出即時原料克數（字體全面加大）**：
     - 隨欲製作數量即時換算所有原料克數並以超大字體呈現，內含自製酵種／特調抹醬（如波蘭種、湯種、法國老麵、乳酪內餡、明太子醬等）亦會自動同步拆解克數。
     - **移除舊版 STEP 3**，操作動線更直覺。
3. **🔄 完整同步最新 Google 試算表 (`gid=2001`)**
   - **原料資料庫擴充至 89 項**：新增「起司」類別、鐵塔法印法國麵粉、法國 Le Gall 燈塔鮮奶油乳酪、靜岡抹茶粉、日本雙葉明太子醬、冷凍藍莓、萬丹紅豆粒餡、富味鄉黑芝麻餡、厚片土司夾鏈袋等。
   - **經典配方庫擴充至 20 款 (`RCP-01` ~ `RCP-20`)**：新增蜂蜜起司軟歐、明太子軟法、蒜香軟法、抹茶紅豆乳酪歐包、巧克力乳酪歐包、芝麻乳酪歐包、藍莓乳酪歐包及各款自製老麵、湯種與內餡抹醬。
   - **成本與定價總覽擴充至 12 款主力販售品項**：後三個管理分頁維持 `0410` 密碼保護。
