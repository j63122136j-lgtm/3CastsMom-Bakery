🚀 GitHub Commit 部署與 iPhone / iPad 安裝指南

✨ 單一檔案零相依架構（Single-File Self-Contained HTML）

本 Dashboard 已將完整 59 項原料資料庫、6 款經典配方、動態比例計算引擎與 Apple 視覺主題封裝為單一獨立網頁檔，無須伺服器後端即可直接部署於 GitHub Pages，並在 iPhone 與 iPad 上以全螢幕 App 模式開啟。

1. 快速 Commit 至 GitHub 並開啟 GitHub Pages 
mkdir jasmine-bakery-dashboard && cd jasmine-bakery-dashboard
# 將下載的檔案命名為 index.html 放入資料夾
git init
git add index.html
git commit -m "feat: Jasmine Bakery Apple-style iOS/iPadOS dashboard"
git branch -M main
git remote add origin https://github.com/<您的帳號>/jasmine-bakery-dashboard.git
git push -u origin main

Push 完成後，前往 GitHub Repository ➔ Settings ➔ Pages ➔ Branch 選擇 main 並點擊 Save，即可獲得專屬網址！

2. 在 iPhone / iPad 上加入主畫面（享受原生 App 全螢幕體驗）
  • 使用 iPhone 或 iPad 的 Safari 打開您的 GitHub Pages 網址。
  • 點擊瀏覽器底部的「分享」圖示（方框向上箭頭）。
  • 向下滑動選擇「加入主畫面 (Add to Home Screen)」。
  • 從主畫面點擊圖示開啟，即會自動隱藏網址列、支援安全區域（Dynamic Island）與深色毛玻璃全螢幕操作！
